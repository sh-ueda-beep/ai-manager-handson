## ADDED Requirements

### Requirement: マルチモーダルレビューリクエスト
AgentCore Runtime は画像を含むスライドに対して、テキストと画像を1つの user メッセージにまとめたマルチモーダルリクエストを Bedrock Claude Vision モデルへ送信しなければならない（MUST）。

#### Scenario: 画像ありスライドのレビューリクエスト
- **WHEN** スライドデータに1枚以上の画像（`images` フィールドが空でない）が含まれる
- **THEN** AgentCore Runtime は以下の構造で Bedrock へリクエストを送信する: `content` 配列にテキストブロック（スライドのタイトル・本文）と画像ブロック（`{ type: "image", source: { type: "base64", media_type, data } }`）を含む

#### Scenario: 画像なしスライドのレビューリクエスト
- **WHEN** スライドデータに画像が含まれない（`images` が空配列）
- **THEN** AgentCore Runtime はテキストのみのリクエストを送信する（既存動作と同一）

#### Scenario: マルチモーダル非対応モデルでの呼び出し
- **WHEN** 設定されたBedrockモデルがマルチモーダル非対応の場合
- **THEN** AgentCore Runtime はエラーを返し、フロントエンドはエラーメッセージを表示する

### Requirement: ビジュアルレビュー観点
AI エージェントは画像を含むスライドに対して以下のビジュアル観点でレビューしなければならない（SHALL）:
- **図の明瞭さ**: 図・グラフ・画像の内容が視覚的に理解しやすいか
- **情報密度**: 1枚のスライドに詰め込まれた視覚的情報量が適切か
- **文字の可読性**: 画像内テキストのフォントサイズ・コントラストが十分か
- **デザイン整合性**: スライド全体のデザインと画像が調和しているか

#### Scenario: 情報過密な図のレビュー
- **WHEN** 複雑な図や過密なグラフが含まれるスライドがレビューされる
- **THEN** AI は視覚的な情報整理や図の分割を提案するコメントを返す

#### Scenario: 可読性の低い画像内テキストのレビュー
- **WHEN** 画像内に小さすぎるテキストや低コントラストの文字が含まれる
- **THEN** AI はフォントサイズの拡大またはコントラスト改善を提案する

#### Scenario: 画像のないスライドへのビジュアル観点適用
- **WHEN** スライドに画像が含まれない
- **THEN** AI はビジュアル観点のコメントを生成しない（テキスト観点のみ）

### Requirement: ビジュアルレビューコメントのフォーマット
AI エージェントはビジュアルレビューコメントをテキストレビューと区別可能な形式で返さなければならない（SHALL）。

#### Scenario: ビジュアルコメントの識別
- **WHEN** 画像を含むスライドのレビュー結果が返される
- **THEN** ビジュアル観点のコメントには「【ビジュアル】」プレフィックスが付与される

#### Scenario: テキストとビジュアルの複合コメント
- **WHEN** テキストと画像の両方を含むスライドがレビューされる
- **THEN** AI はテキスト観点とビジュアル観点の両方のコメントを返す
